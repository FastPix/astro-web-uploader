# FastPix Astro Uploader — example

Minimal Astro app demonstrating `<FastPixUploader />` from the published
[`@fastpix/fp-astro-uploader`](https://www.npmjs.com/package/@fastpix/fp-astro-uploader)
package.

```bash
npm install
npm run dev
```

Open the printed URL, paste a FastPix signed upload URL, and pick a file.
